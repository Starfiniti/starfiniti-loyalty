# Data Classification

- **Restricted:** authentication secrets, WooCommerce credentials, Supabase secret keys, signing secrets.
- **Confidential:** customer identifiers, contact data, order associations, exports.
- **Internal:** audit metadata, programme drafts, operations and diagnostics.
- **Public:** published marketing copy and intentionally exposed programme rules.

Restricted values never enter browser bundles, logs, repository files, or support bundles.
