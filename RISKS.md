# Risk Register

| ID    | Risk                                                                                                           | Impact   | Mitigation                                                                                                                                                                                                        | Status                |
| ----- | -------------------------------------------------------------------------------------------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| R-001 | Tenant data crosses organization boundaries                                                                    | Critical | RLS on every exposed tenant table plus adversarial read/command tests                                                                                                                                             | Mitigated through P9  |
| R-002 | Duplicate/out-of-order WooCommerce events alter balances twice                                                 | Critical | Signed inbox, unique source/effect IDs, ledger idempotency, reconciliation                                                                                                                                        | Mitigated through P7  |
| R-003 | Self-hosted Supabase upgrades break gateway/auth routing                                                       | High     | Pin self-hosted releases; Envoy-first config; staged upgrade/rollback tests                                                                                                                                       | Mitigated by ADR-0002 |
| R-004 | Proxmox host failure causes authoritative data loss                                                            | Critical | Off-host encrypted backups, PITR, scheduled restore drills                                                                                                                                                        | Open                  |
| R-005 | Central outage breaks merchant checkout                                                                        | Critical | Thin async plugin, local outbox, Action Scheduler, no checkout network calls                                                                                                                                      | Partially mitigated   |
| R-006 | Repository license does not match open-source business intent                                                  | High     | AGPL-3.0-or-later approved for platform; WooCommerce plugin remains GPL-2.0-or-later                                                                                                                              | Mitigated             |
| R-007 | Design prototype localStorage rules are mistaken for production truth                                          | High     | Treat prototype as UX spec only; encode behavior through approved domain decisions                                                                                                                                | Mitigated             |
| R-008 | Declared WooCommerce compatibility exceeds executed release evidence                                           | High     | Slovenian joins smoke; extend all PHP, money, cache, lifecycle, language, and RTL cases                                                                                                                           | Partially mitigated   |
| R-009 | Merchant branding injects executable CSS or remote tracking assets                                             | High     | Persist validated design tokens only; separate reviewed asset/CSS pipeline                                                                                                                                        | Mitigated through P9  |
| R-010 | Bulk administration creates stale, partial, duplicate, or unauthorized value effects                           | Critical | Cap at 50; exact read-only preview hash; deterministic locks; atomic per-customer ledger effects; live owner/admin checks; immutable batch audit                                                                  | Mitigated through P9  |
| R-011 | Customer locale selection exposes unsafe copy or mixes tenant translations                                     | High     | Allowlist launch locales; bound control-free copy; composite scope keys and RLS; owner/admin-only idempotent revisions; omit copy from audit metadata                                                             | Mitigated through P9  |
| R-012 | Anonymous hosted delivery exposes private tenant, customer, or programme evidence                              | Critical | One reviewed SECURITY DEFINER projection; exact active linked scope; published-only bounded allowlist; no source-table grants; adversarial no-effect tests                                                        | Mitigated through P9  |
| R-013 | Customer account claim links the wrong wallet or leaks a reusable capability                                   | Critical | Five-minute channel HMAC; explicit signed-in confirmation; hashed one-use nonce/proof; unique active links; no email merge; private no-referrer response                                                          | Mitigated through P9  |
| R-014 | Customer reward redemption overspends, crosses tenants, leaks coupon capability, or strands ambiguous commands | Critical | Auth-derived scope; exact request/hash; wallet/FIFO locks; atomic reserve/transition/outbox; private coupon payload; pre-publication native-cap guard; ten-attempt manual review without speculative compensation | Mitigated through P9  |
| R-015 | Customer erasure leaks a reusable source identity, loses value history, or re-imports                          | Critical | Opaque local key; strict event; private keyed tombstone; atomic link revocation and pseudonymization; raw-event scrub; import suppression; ledger retention                                                       | Mitigated through P9  |
| R-016 | Locale continuation enables an open redirect or changes customer-link authority                                | High     | Exact locale allowlist; local-path-only continuation; locale excluded from signed claim identity; private Auth navigation; route and runtime tests                                                                | Mitigated through P9  |
| R-017 | Customer export leaks another subject, survives reuse, or persists sensitive content                           | Critical | Password reauth; five-minute subject/session-bound hashed token; atomic one-use consume; no-selector projection; direct no-store download; immutable audit                                                        | Mitigated through P9  |
| R-018 | Connector setup leaks, reuses, or stores signing material in a browser-facing boundary                         | Critical | Root-readable key pool; runtime-only provisioning; unique references; one-result setup package; encrypted plugin storage; secret-free audit and Data API                                                          | Mitigated through P9  |
| R-019 | Initial tenant bootstrap grants the wrong Auth user or leaves partial/duplicate scope                          | Critical | Existing Auth UUID; exact slug confirmation; atomic owner-only transaction; stable idempotency; existing-scope denial; immutable minimized audit                                                                  | Live verification due |
| R-020 | Merchant locale or server timezone changes the meaning of an administrative command                            | High     | Exact locale allowlist; locale-bound forms; shared Europe/Ljubljana parsing; DST gap/ambiguity rejection; unit and responsive browser tests                                                                       | Mitigated through P9  |
